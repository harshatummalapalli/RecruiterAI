# RecruiterAI MVP

## Scope

### Input
- Paste Job Description

### Processing
- AI parses the JD
- AI generates search intent
- AI generates Crustdata search queries
- Crustdata returns candidates
- AI ranks candidates
- Harvest enriches top candidates
- AI re-ranks candidates

### Output
- Ranked candidate table
- Export to Excel
