# RecruiterAI PRD

## Vision

Build an AI-powered recruiting assistant that enables recruiters to paste a Job Description and automatically receive a ranked list of highly relevant candidates.

The recruiter should never have to write Boolean searches, understand APIs, or configure technical filters.

---

# User

Technical Recruiter / Talent Acquisition Specialist

---

# User Journey

1. Recruiter pastes a JD.
2. AI understands the hiring intent.
3. AI generates one or more search strategies.
4. System searches Crustdata.
5. Results are merged and deduplicated.
6. AI ranks candidates.
7. Top candidates are enriched using HarvestAPI.
8. AI re-ranks candidates.
9. Recruiter reviews the final ranked shortlist.
10. Recruiter exports results to Excel.

---

# Success Criteria

A recruiter can obtain a high-quality shortlist in under 2 minutes with almost no manual searching.
